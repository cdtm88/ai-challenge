The register, as a document of record

Drafted from the weekly meeting transcript, the ticket export and the reported RAG board. Every item is typed before it is scored, cites its sources, and states where those sources disagree. Nothing here is accepted until a human accepts it.

Acceptance is recorded for this browser session only. It is held in sessionStorage and restored on reload; closing the tab clears it. The prototype demonstrates the adjudication loop without pretending to persist it.

Omitted from this register

Findings that could not be traced to a source this week. They are named here with a reason rather than carried forward on last week's quote.

Two prompt passes, extract-and-classify then score, run offline. The model emits factor scores against written anchors; every total, band, ordering and movement state is computed in code by score.py, so the arithmetic is reproducible and the same week ranks the same way every time.

All content is self-created. No real organisation, client, colleague or project appears, and speakers are role labels only. There is no model call at view time, no server component, no credentials, and no request to any origin but this one.
