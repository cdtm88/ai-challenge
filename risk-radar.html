How the scores work

Every finding is typed before it is scored, because type decides the scale. An issue has already happened, so it carries impact alone and never a likelihood.

Exposure
Risks only. Impact multiplied by likelihood, 1 to 25. Bands: 15–25 critical, 10–14 high, 5–9 medium, 1–4 low.
Impact
Issues, 1 to 5. 1 is absorbed inside the workstream; 5 breaks a commitment made outside the programme.
Criticality
Dependencies, 1 to 5. 1 is desirable; 5 means the release depends on it and there is no alternative path.
Coverage
Assurance gaps carry counts, not a score. A workstream nobody can see is not scored as though it were understood.
Attention
Every type, 0 to 5. Proximity 0.35, blast radius 0.25, control status 0.25, evidence confidence 0.15. It orders items inside a band and never changes the band.

The model scores each factor against a written anchor and emits nothing else. Every total, band, ordering and movement state is computed in code by score.py, so the same week ranks the same way every time.
